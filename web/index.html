One state for every orange

State What the camera sees What you do
Unripe Mostly green peel Leave it on the tree.
Ripening Green turning yellow or orange Check again in a few days.
Ready to pick Even, deep orange peel Harvest it.

How it’s built

So far

The browser scanner and the Telegram photo check estimate ripeness from peel colour. The bot runs on a team laptop with demo scans and simulated readings.

Next

Finish the laptop camera program. YOLO finds each orange and the colour check judges its ripeness. Then connect the camera feed and the sensor board to the bot.

The control room

On the laptop, a read-only control room shows the latest camera frame with each orange boxed, the count ready to pick, the watering advice and an activity feed. It only runs on the farm laptop. This public page is a snapshot made from demo data.

See the control room (demo data)

The sensor board

The Arduino reads soil moisture, temperature and humidity. The team is still connecting it. The watering advice uses those readings and the forecast, with simulated readings in the prototype today.

Why oranges

We built this at Cutiehacks in Riverside, a city that grew up on oranges. The tree that started California’s navel orange industry still stands here.

We started with two questions a grower asks while walking the rows: which oranges are ready to pick, and does the grove need water?
